# Original soundtrack recordings

This folder is intentionally empty of audio until the game creator uploads
the authorized M4A recordings. Do not substitute synthetic audio.

To add via the GitHub website, open this folder and use **Add file → Upload files**;
drag in the original .m4a tracks from the Dust & Debt soundtrack and commit to
main. Other computers can then run `git pull origin main`.

The required original filenames and scene assignments are in
[`soundtrack_manifest.py`](../../../soundtrack_manifest.py).
The title track is `Forsaken to This Land.m4a`.
